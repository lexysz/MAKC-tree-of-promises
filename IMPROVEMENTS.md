### 2. **Логотип компании в корневых обещаниях**

**Идея:** Использовать логотип компании, загруженный в админке, перекрашенный в цвет узла ценности.

**Реализация:**
- SVG filter `feColorMatrix` для перекрашивания логотипа
- Автоматическое извлечение RGB из hex-цвета узла
- Применение фильтра к `<image>` элементу
- Fallback на текст, если логотип не загружен

**Код перекрашивания:**
```typescript
<filter id={`recolor-${node.id}`}>
  <feColorMatrix
    type="matrix"
    values={`0 0 0 0 ${parseInt(color.slice(1, 3), 16) / 255}
             0 0 0 0 ${parseInt(color.slice(3, 5), 16) / 255}
             0 0 0 0 ${parseInt(color.slice(5, 7), 16) / 255}
             0 0 0 1 0`}
  />
</filter>
```

**Преимущества:**
✅ Визуальная связь всех обещаний с брендом компании  
✅ Цветовая кодировка принадлежности к ценности  
✅ Компактное и красивое отображение  
✅ Автоматическая адаптация под цвет ценности  

### 3. **Иерархическая нумерация (1.1, 1.2, 2.1...)**

**Формат:**
- Первая цифра — номер ценности (по порядку расположения по кругу)
- Вторая цифра — номер корневого обещания внутри ценности

**Пример:**
```
Ценность 1 (Надёжность):
  - 1.1 Сервис доступен 24/7
  - 1.2 Стабильность важнее новых функций

Ценность 2 (Скорость):
  - 2.1 Ответ клиенту — в течение дня
```

**Реализация:**
```typescript
const rootNumbers = useMemo(() => {
  const numbers = new Map<string, string>();
  
  // Получаем все ценности в порядке их расположения по кругу
  const valueNodes = nodes.filter((n) => n.tier === "value");
  const sortedValues = [...valueNodes].sort((a, b) => {
    const angleA = Math.atan2(a.y, a.x);
    const angleB = Math.atan2(b.y, b.x);
    return angleA - angleB;
  });
  
  // Для каждой ценности находим её корневые обещания
  sortedValues.forEach((valueNode, valueIndex) => {
    const rootNodes = nodes.filter((n) => n.tier === "root" && n.parentId === valueNode.id);
    const sortedRoots = [...rootNodes].sort((a, b) => {
      const angleA = Math.atan2(a.y, a.x);
      const angleB = Math.atan2(b.y, b.x);
      return angleA - angleB;
    });
    
    sortedRoots.forEach((rootNode, rootIndex) => {
      numbers.set(rootNode.id, `${valueIndex + 1}.${rootIndex + 1}`);
    });
  });
  
  return numbers;
}, [nodes]);
```

**Отображение:**
- Номер отображается в правом нижнем углу круга
- Цвет номера совпадает с цветом узла
- Размер шрифта: 14px, жирный (700)
- Позиция: `x = r * 0.6`, `y = r * 0.6`

**Преимущества:**
✅ Лёгкая идентификация обещаний  
✅ Понимание иерархии и структуры  
✅ Удобство для ссылок в документации  
✅ Компактное отображение

## 📊 Технические детали

### SVG Filter для перекрашивания

**Принцип работы:**
- `feColorMatrix` с типом `matrix` позволяет заменить все цвета изображения
- Матрица 5x4 преобразует RGB значения
- Первые три строки устанавливают новые RGB значения
- Четвёртая строка сохраняет альфа-канал

**Матрица преобразования:**
```
R_new = R_old * 0 + G_old * 0 + B_old * 0 + target_R
G_new = R_old * 0 + G_old * 0 + B_old * 0 + target_G
B_new = R_old * 0 + G_old * 0 + B_old * 0 + target_B
A_new = A_old * 1
```

**Преобразование hex в RGB:**
```typescript
const r = parseInt(color.slice(1, 3), 16) / 255;
const g = parseInt(color.slice(3, 5), 16) / 255;
const b = parseInt(color.slice(5, 7), 16) / 255;
```

### Сортировка узлов по углу

**Зачем:** Для определения порядка нумерации ценностей и обещаний.

**Алгоритм:**
1. Вычисляем угол каждого узла через `Math.atan2(y, x)`
2. Сортируем узлы по возрастанию угла
3. Присваиваем номера в порядке сортировки

**Результат:**
- Нумерация идёт по часовой стрелке, начиная с 12 часов
- Порядок соответствует визуальному расположению на дереве

1. Войдите в админ-панель (admin/promises)

3. Нажмите "Загрузить логотип"

5. Сохраните изменения

### Нумерация:
Нумерация генерируется автоматически на основе структуры дерева. Номера отображаются в правом нижнем углу каждого корневого обещания.
