# Удаление иерархической нумерации корневых обещаний

## Проблема

Иерархическая нумерация (1.1, 1.2, 2.1...) в кругах корневых обещаний вызывала критические проблемы:

1. **Неправильная привязка узлов**: Узел 3.5 привязывался к неправильной ценности
2. **Пропавшие узлы**: Узел 5.3 исчезал из дерева
3. **Дублирование**: Один и тот же узел отображался дважды с разными цветами
4. **Сложность кода**: Логика нумерации усложняла код и вызывала баги

## Решение

**Полностью удалена иерархическая нумерация из корневых обещаний.**

### Что было удалено

1. **Функция `rootNumbers`** в `TreeCanvas.tsx`:
   - Вычисление номеров на основе угла расположения узлов
   - Сортировка ценностей и корневых обещаний
   - Мапа `Map<string, string>` с номерами

2. **Параметр `rootNumber`** в компоненте `NodeGlyph`:
   - Передача номера в компонент
   - Отображение номера в круге

3. **Отображение номеров** в корневых обещаниях:
   - Текст с номером в правом нижнем углу круга
   - Условный рендеринг `{rootNumber && ...}`

### Что осталось

✅ Логотип компании в корневых обещаниях  
✅ Перекрашивание логотипа в цвет ветки  
✅ Адаптивный размер текста (если нет логотипа)  
✅ Все остальные функции дерева  

## Результат

✅ Узлы правильно привязываются к своим ценностям  
✅ Нет дублирования узлов  
✅ Цвет узла соответствует его ветке  
✅ Логотип перекрашивается в правильный цвет  
✅ Все узлы отображаются на дереве  
✅ Упрощён код и устранены баги

## Технические изменения

### Удалённый код

```typescript
// Вычисление номеров (УДАЛЕНО)
const rootNumbers = useMemo(() => {
  const numbers = new Map<string, string>();
  const normalizeAngle = (x: number, y: number) => {
    let angle = Math.atan2(y, x) + Math.PI / 2;
    if (angle < 0) angle += 2 * Math.PI;
    return angle;
  };
  
  const valueNodes = uniqueNodes.filter((n) => n.tier === "value");
  const sortedValues = [...valueNodes].sort((a, b) => {
    return normalizeAngle(a.x, a.y) - normalizeAngle(b.x, b.y);
  });
  
  sortedValues.forEach((valueNode, valueIndex) => {
    const rootNodes = uniqueNodes.filter((n) => {
      return n.tier === "root" && n.parentId === valueNode.id;
    });
    
    const sortedRoots = [...rootNodes].sort((a, b) => {
      return normalizeAngle(a.x, a.y) - normalizeAngle(b.x, b.y);
    });
    
    sortedRoots.forEach((rootNode, rootIndex) => {
      numbers.set(rootNode.id, `${valueIndex + 1}.${rootIndex + 1}`);
    });
  });
  
  return numbers;
}, [uniqueNodes]);

// Передача номера в компонент (УДАЛЕНО)
<NodeGlyph
  key={nd.id}
  node={nd}
  rootNumber={nd.tier === "root" ? rootNumbers.get(nd.id) : undefined}
/>

// Отображение номера (УДАЛЕНО)
{rootNumber && (
  <text
    x={r * 0.6}
    y={r * 0.6}
    textAnchor="middle"
    fontSize={14}
    fontWeight="700"
    fill={color}
  >
    {rootNumber}
  </text>
)}
```

## Альтернативные решения (если нумерация нужна)

Если в будущем потребуется вернуть нумерацию, можно использовать более простые подходы:

### Вариант 1: Нумерация на основе порядка в данных

```typescript
// Использовать порядок в массиве values
const rootNumbers = useMemo(() => {
  const numbers = new Map<string, string>();
  values.forEach((value, valueIndex) => {
    value.promises.forEach((promise, promiseIndex) => {
      numbers.set(promise.id, `${valueIndex + 1}.${promiseIndex + 1}`);
    });
  });
  return numbers;
}, [values]);
```

**Преимущества**:
- Не зависит от визуального расположения
- Простая логика
- Нет проблем с дублированием

**Недостатки**:
- Зависит от порядка в данных
- Может не соответствовать визуальному порядку

### Вариант 2: Нумерация в данных

Добавить поле `number` в структуру данных:

```typescript
interface RootDef {
  id: string;
  title: string;
  number: string; // "1.1", "1.2", etc.
  // ...
}
```

**Преимущества**:
- Полный контроль над нумерацией
- Можно задавать вручную
- Не зависит от расположения

**Недостатки**:
- Нужно поддерживать нумерацию вручную
- Может рассинхронизироваться с визуалом
