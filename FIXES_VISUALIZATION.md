### 1. Логотип в корневых обещаниях не появлялся

**Проблема:** companyLogo передавался только для узлов tier === "company", но не для tier === "root".

**Решение:** Изменено условие передачи companyLogo на строке 400:

**Результат:** Теперь логотип компании отображается и в ядре, и во всех корневых обещаниях.

### 3. Ломалась иерархическая нумерация (1.1, 1.2, 5.6, 1.4)

**Проблема:** Сортировка по углу через `Math.atan2(y, x)` давала неправильный порядок при переходе через границу -π/π. Например, узлы с углами -179° и 179° должны быть рядом, но сортировка ставила их в разные концы списка.

**Решение:** Добавлена функция нормализации угла, которая:
1. Поворачивает систему координат на 90° (чтобы 12 часов было 0)
2. Нормализует угол в диапазон [0, 2π]
3. Обеспечивает корректную сортировку по часовой стрелке

**Код:**
```typescript
const normalizeAngle = (x: number, y: number) => {
  let angle = Math.atan2(y, x) + Math.PI / 2; // Поворот на 90°
  if (angle < 0) angle += 2 * Math.PI;
  return angle;
};

// Сортировка ценностей
const sortedValues = [...valueNodes].sort((a, b) => {
  return normalizeAngle(a.x, a.y) - normalizeAngle(b.x, b.y);
});

// Сортировка корневых обещаний внутри ценности
const sortedRoots = [...rootNodes].sort((a, b) => {
  return normalizeAngle(a.x, a.y) - normalizeAngle(b.x, b.y);
});
```

**Результат:** Нумерация теперь корректна: 1.1, 1.2, 2.1, 2.2, 3.1... без пропусков и перемешивания.

## 📊 Технические детали

### Нормализация угла

**Проблема с Math.atan2:**
- Диапазон: [-π, π]
- Граница: -π и π представляют одно и то же направление
- Сортировка: -179° < 179°, хотя они должны быть рядом

**Решение:**
1. Поворот на 90°: `angle + Math.PI / 2`
   - 12 часов (0, -1) → 0°
   - 3 часа (1, 0) → 90°
   - 6 часов (0, 1) → 180°
   - 9 часов (-1, 0) → 270°

2. Нормализация в [0, 2π]:
   ```typescript
   if (angle < 0) angle += 2 * Math.PI;
   ```

3. Результат: монотонная последовательность углов от 0 до 2π

### Перекрашивание логотипа

**SVG Filter feColorMatrix:**
```xml
<filter id="recolor-${node.id}">
  <feColorMatrix
    type="matrix"
    values="0 0 0 0 R
            0 0 0 0 G
            0 0 0 0 B
            0 0 0 1 0"
  />
</filter>
```

**Преобразование hex в RGB:**
```typescript
const r = parseInt(color.slice(1, 3), 16) / 255;
const g = parseInt(color.slice(3, 5), 16) / 255;
const b = parseInt(color.slice(5, 7), 16) / 255;
```

**Принцип работы:**
- Матрица заменяет все цвета изображения на один цвет
- Альфа-канал сохраняется (последняя строка)
- Каждый узел получает уникальный filter id
