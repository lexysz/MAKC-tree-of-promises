# Дерево обещаний - Восстановленный функционал

## ✅ Восстановленный функционал

### 1. **Визуализация дерева**
- Радиальное дерево с тремя уровнями: ценности → корневые → поддерживающие
- Структура циферблата: ценности равномерно по кругу, обещания в конусах
- Увеличенные узлы: ценности (324px), корневые (120px), поддерживающие (60px)
- Прямые линии связей без пересечений
- Трёхфазный алгоритм разрешения пересечений

### 2. **Интерактивность**
- Масштабирование: колесо мыши / кнопки +/- (диапазон 0.08x - 4x)
- Панорамирование: перетаскивание мышью
- Зум на ветку: клик по узлу центрирует всю связанную ветку
- Адаптивный дизайн: десктоп и мобильные устройства

### 3. **Админ-панель**
- Авторизация: admin / promises
- Редактирование всех узлов дерева
- Загрузка логотипа компании (PNG)
- Редактируемая надпись под центральным кружком
- Drag & Drop узлов для ручной настройки позиций
- Сброс пользовательских позиций

### 4. **Импорт из Excel**
- Парсер Excel файлов с автоматическим распознаванием колонок
- Колонки: Кто дает обещание, Кому, ЦЕННОСТЬ, Корневое обещание, Метрики, Поддерживающее обещание, Кто дает, Кому, Метрики
- Поддержка множественных поддерживающих обещаний (Alt+Enter)
- Шаблон Excel для скачивания
- Статистика импорта и предупреждения

### 5. **Сохранение данных**
- localStorage для всех изменений (версия v7)
- Автоматическое сохранение при редактировании
- Уникальные цвета для каждой ценности (золотое сечение)
- Сброс к исходным данным

### 6. **UI/UX**
- Темная тема с градиентами
- Анимации появления узлов и связей
- Тултипы при наведении
- Панель деталей с метаданными (кто даёт, кому, метрики)
- Легенда и подсказки
- Кнопки управления масштабом

## 🎨 Особенности реализации

1. **Алгоритм размещения узлов:**
   - Ценности равномерно по кругу (valueAngleStep = 2π / N)
   - Корневые в секторе ценности (rootStep = sectorWidth / rootCount)
   - Поддерживающие в секторе корневого (supportStep = subSectorWidth / supportCount)
   - Это гарантирует отсутствие пересечений между ветками

2. **Разрешение пересечений:**
   - Фаза 1: раздвижение узлов внутри уровня (100 итераций)
   - Фаза 2: раздвижение между уровнями (60 итераций)
   - Фаза 3: сдвиг узлов при пересечении линий (30 итераций)

3. **Масштабирование:**
   - Динамический расчет радиусов колец
   - Адаптация под количество узлов
   - NODE_GAP = 100px для предотвращения пересечений
